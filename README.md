# Pong Game

A classic two-player Pong game built with Pygame.

## Requirements

- Python 3.x
- Pygame

Install Pygame:
```bash
pip install pygame
```

## Required Files

Make sure these files are in the same directory as the game:
- `fond.jpg` - Background image
- `ball.png` - Ball sprite
- `raquette.png` - Paddle sprite
- `start_sound.wav` - Game start sound
- `goal_sound.wav` - Goal scored sound
- `win_sound.wav` - Victory sound

## How to Play

Run the game:
```bash
python pong_game.py
```

### Controls

**Player 1 (Left):**
- Arrow Keys to move paddle

**Player 2 (Right):**
- W/A/S/D keys to move paddle

### Rules

- First player to score 10 goals wins
- Ball speed increases with each paddle hit
- Press SPACE for smash (if implemented)

## Game Features

- Two-player local multiplayer
- Score tracking
- Sound effects
- Dynamic ball acceleration
- Win condition at 10 points
